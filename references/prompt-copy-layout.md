# 文案、图片 Prompt 与专业电商排版

## 一一对应的资产任务卡

每张计划交付的图片必须有唯一 `asset_id`。同一 `asset_id` 贯穿任务卡、底图、排版稿、最终图、contact-sheet、质检报告和 manifest，禁止跨图复用未核对的文案或 Prompt。

任务卡至少包含：

- 输出分支、槽位、图片类型、画布尺寸和版本。
- 沟通目标、目标人群、核心卖点和期望阅读顺序。
- 产品事实引用、竞品视觉证据引用和禁用主张。
- 视觉语言与差异化：引用第 2 步视觉语句库 `visual_phrase_id`（VP）与增值产物 A/C/D——底图视觉手法用 A 的市场手法、差异化用 A 的机会与 C 的机会清单、负面用 C 的风险库、版式用 D 的层级参考。
- 对应文案：主标题、辅助说明、数据、标签或 `none`。
- 无字底图 Prompt：基准方向、必要时的方向 A/B、负面约束；视觉语言必须落进选中的 `visual_phrase_id` 语句（含来源）。
- 产品不变量：结构、颜色、接口、标签、配件及数量。
- 场景与镜头：场景、动作、`viewpoint_id`、景别、机位、产品朝向、产品占比和裁切。
- 版式规划：目标画布、场景覆盖方式、产品区、文案安全区、视觉动线、**版式原型（选自 `dynamic-image-type-library.md`「差异化版式原型」表中本图片类型的某一原型，与图片类型一一对应）**、字体层级、色彩、图标和移动端适配；同类型重复（配额内）时必须换用不同原型或不同景别/占比/动线。
- 套图关系：最相近的既有 `asset_id`、允许延续的品牌元素，以及必须变化的沟通、场景、镜头或版式维度。

白底首图的文案字段必须为 `none`。其他图片也不强制有文字；只有文字能提升理解且有可靠事实时才排版。

## 文案策划

- 每张图只承担一个主要沟通目标，标题优先表达用户收益，辅助说明补充事实或机制。
- 文案必须能追溯到用户事实或授权材料；竞品表达只能启发结构，不得照抄。
- 竞品卖点文案（标题、五点、图上字的内容）不做本产品卖点来源，也不得当作本产品事实；竞品研究只提供视觉语言与「品类常规卖点」的弱参考。
- 数据、比较、认证、保修和绝对化用语必须附证据引用；无法证明时删除或降级。
- 用户文案里的卖点若未证实（性能、认证、数据），标为 `claim`；只在有证据时才用强主张可视化（如数据图表），否则降级为弱表达（场景化/暗示，不写具体数字）。
- 文案长度服从画面层级和移动端可读性，不为填满版面堆叠卖点。

## 跨分支叙事与差异门禁

主图与 A+ 承担不同阶段的说服任务：主图（白底首图与其余主图图片）建立产品身份、快速表达购买理由，A+ 深化机制与证据、展示完整使用情境、回答异议并建立品牌信任。二者可以围绕同一核心卖点形成连续叙事，但不能重复堆叠同一表达。基础 A+、PC 端高级 A+ 与移动端高级 A+ 共用同一 A+ 叙事，区别仅在画布尺寸与版式。

在计划某一分支时（无论该分支在先还是在后、是否同时生成），相对**已产出的分支**：

1. 读取既有任务卡和最终图，列出已覆盖的卖点、场景、文案、视角、景别和版式原型。
2. 建立信息缺口表，优先把本分支槽位分配给尚未回答的机制、证据、步骤、完整场景、异议、对比或品牌内容；若本分支是主图，则优先补产品身份与购买理由。
3. 为每张图记录最相近的既有资产及 `novelty_delta`。画布尺寸变化不算差异；默认至少在“沟通或文案重点、场景或动作、角度或景别、产品占比或裁切、构图或版式原型”中形成两项实质变化。
4. 同一卖点再次出现时必须向下深化，例如从利益点推进到原理、证据、使用细节或异议解答，不得只改写标题。
5. 同类场景可用于品牌连续性，但应改变人物动作、拍摄时段、空间区域、机位、远近或产品与环境的关系；原场景、原视角、原文案与原版式的组合不得直接复用。

先完成整套图的镜头与版式矩阵，再写单图 Prompt。若产品实拍能可靠支持多个视角，套图应覆盖正面/三分之四、侧面、顶部或底部、细节等与卖点有关的视角族。对于 6 张及以上的套图，“少于 3 个可验证视角族”“超过半数图片使用同一产品视角”或“同一版式骨架连续出现 3 次”都视为需要说明并优先重策划的重复预警；系列步骤图等有明确叙事理由时可以例外。

品牌一致性主要由字体、色板、图标风格、光线逻辑和材质语言维持，不以所有图片保持同一产品位置和左右分栏实现。版式原型应由沟通目标决定，可使用全景沉浸、非对称主视觉、微距细节、步骤序列、数据证明、对比或品牌叙事等不同结构。

## 无字底图 Prompt 结构

按以下顺序组合，不必机械使用固定句式：

1. 图片目标与图片类型。
2. 产品主体与必须保持的身份特征。
3. 构图、镜头、主体位置和文案留白。
4. 场景、人物或道具及其与产品的关系。
5. 光线、色调、材质、质感和细节层级。
6. 卖点的视觉化动作或状态。
7. 画布、裁切和输出适配要求。
8. 负面约束：错误结构、额外配件、错误文字、形变、伪数据、品牌混入等。

基准 Prompt 是最稳妥的事实表达。方向 A/B 必须代表真实不同的传播策略，例如“理性功能证明”与“情绪化生活场景”，而不是只换颜色或形容词。没有真实决策差异时不要制造变体。

场景主导的 A+ Prompt 必须直接描述目标宽高比下的完整环境、前中后景和边缘延展，生成适配目标画布的场景，而不是把已完成的方图放进宽画布后用纯色补齐。纯色或信息面板只适用于任务卡明确标记的信息主导版式，不能作为场景不足的补丁。

## 先生成图片，再做图文排版

1. Prompt 阶段明确文案安全区，但不在图片模型中生成最终文字。
2. 生成并筛选无字底图，先通过产品一致性、清晰度和构图检查。
3. 基于最终底图规划字体层级、阅读顺序、网格、对齐、留白、颜色、对比度和品牌元素。
4. 用 SVG、HTML/CSS、PSD 或其他可编辑方式加入真实文案、尺寸线、图标和数据；制作格式不等于用户交付格式。
5. 重点图在版式存在明显不确定性时可做两个候选；按电商信息效率、视觉层级、品牌一致性和移动端可读性选优。
6. 只修改排版层即可解决的问题不得重新生成底图。

## 排版质量标准

- 产品主体和关键结构不被标题、图标、尺寸线或装饰遮挡。
- 主标题、辅助说明、数据和标签层级清晰，第一眼能识别单一核心卖点。
- 文字与背景有足够对比度，边距、安全区和对齐一致。
- PC 与移动版不是简单等比缩小；重新检查裁切、字号、行长和触控端阅读距离。
- 桌面端和移动端保留同一叙事与事实，但允许采用不同景别、主体位置和版式；若裁切会损失场景语义，则生成或合成独立母版。
- OCR、拼写、单位、数字和品牌名与任务卡一致。
- 不使用图片模型生成的乱码作为最终文字。

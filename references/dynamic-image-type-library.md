# 动态图片类型库

## 使用方式

图片类型库是候选集合，不是每套图都必须覆盖的检查清单。根据输出槽位、产品事实、核心卖点、用户痛点、视觉证据、制作可行性和合规风险选择最小但完整的组合；用户明确偏好优先于自动选择，但不能覆盖事实与合规约束。

为每个候选类型记录：`image_type_id`、沟通目标、必要证据、生成方式、排版方式、风险和适用输出分支。

类型选择与输出分支正交：主图与 A+ 均可套用**任一内容类型**；A+ 只是在应用层额外叠加「A+ 槽位结构」与对应约束。某个内容类型放入 A+ 时，须同时满足该内容类型自身的约束（含证据门禁）与该 A+ 槽位约束。

## 类型全集

### 产品身份与事实证明

- 白底首图、白底副图、多角度展示图、组合展示图。
- 尺寸图、比例参照图、包装清单图、变体展示图。
- 细节图、微距图、材质/工艺图、结构拆解图、剖面/原理示意图。
- 兼容性图、接口/适配图、成分/配方图。
- 数据/性能图、防护能力图、认证/授权图。

### 使用方式与用户收益

- 单一场景图、多场景组合图、人物使用图、手部交互图。
- 功能演示图、使用步骤图、安装/组装图、清洁/维护图。
- 多用途图、收纳/便携图、痛点解决图、使用前后对比图。
- 季节图、礼赠图、目标人群图。

### 说服、品牌与叙事

- 核心卖点图、信息图、性能对比图、型号对比图。
- 情绪氛围图、品牌故事图、设计灵感图、服务保障图。

该列表开放扩展。出现新类型时，只有在其沟通目标、证据门槛和生成/排版方式能够明确时才加入本次计划。

## 动态选择规则

1. 先确定输出槽位和不可变要求。主图分支必须包含合规白底首图；其他槽位不预设固定类型。
2. 为产品建立消息优先级：产品身份 → 核心卖点 → 事实证明 → 使用场景 → 异议化解 → 品牌信任。
3. 给候选类型按相关性、证据强度、视觉表现力、差异化、制作可行性和合规性评分，同时扣除与已选图片的内容重复。
4. 选择能覆盖高优先级消息的最少类型组合。不要为了“类型丰富”重复同一卖点。
5. 将用户偏好作为加权项；偏好与平台规则、证据或产品身份冲突时说明并降级。
6. 为每个选中类型写清“为什么是这张图、证明什么、用什么事实、如何生成、如何排版”。

若一次任务包含多个输出分支，或用户在主图完成后追加 A+，候选类型的重复扣分必须跨分支计算。A+ 不按主图的卖点顺序逐张翻版，而是优先补足信息深度和叙事缺口；只有确有承上启下作用时才保留少量主题呼应，并为场景、镜头、文案功能和版式重新设计。

## 类型配额（按分支独立计算）

每个分支内的同一内容类型有数量上限，防止一套图被单一类型占满；主图与 A+ 的配额**各自独立、互不占用**，同类型在主图里用过的张数**不计入** A+ 侧。

- 主图分支：每个内容类型最多 **2 张**；白底首图固定 1 张，不计入配额。
- A+ 分支：每个内容类型最多 **3 张**（A+ 三种尺寸变体共用叙事，统一计数）。
- 超过上限时，要么**换另一种类型**表达该卖点/画面，要么保证同类型的每次出现与已出现的同类型图有**≥2 项实质差异**（不同卖点/场景/角度/景别/版式）；否则判为重复，返回策划。

## 类型决策记录（每分支一份，选择结果）

类型选择须输出一份**决策记录**，让选择可辩护、可追溯：

- 分支（主图 / A+；A+ 三种尺寸变体共用一份）。
- 必选类型：主图 → 白底首图。
- 选中的候选类型 N 个，每条标注：`image_type_id`、为什么是这张图（角色）、证明什么（卖点）、用什么事实/证据（来源：用户事实 / 竞品 VP / 实拍）、如何生成与排版（引用生成路由、第 2 步 A 手法、D 版式）。
- 考虑过但排除的类型，每条标注：`image_type_id`、排除原因（证据缺失<缺某事实> / 与已选重复 / 合规风险 / 不适配本分支）。
- 用第 2 步 A（卖点×图型×手法）与 C（机会/风险）驱动，并受类型配额约束。

## 类型特定约束

| 图片类型 | 必要约束 | 推荐制作方式 |
|---|---|---|
| 白底首图 | 产品身份准确；无文案、装饰或额外配件 | 实拍抠图或受控产品编辑，纯白背景 |
| 尺寸/比例图 | 数值、单位和参照物比例有证据 | 干净底图 + 矢量尺寸线与文字 |
| 细节/材质图 | 特写部位与材质可由实拍确认 | 对应视角实拍或局部受控编辑 |
| 场景图 | 使用方式、环境和产品尺度合理 | 场景生成/合成，产品区域锁定 |
| 人物/手部图 | 人群、动作、接触关系和肢体真实 | 生成场景后重点检查人体与产品交互 |
| 拆解/剖面/原理图 | 零件、层级、内部结构有明确资料 | 证据驱动的图解或 3D/矢量示意 |
| 包装清单图 | 配件名称与数量已确认 | 实拍组合或干净合成 + 矢量标签 |
| 功能/步骤/安装图 | 操作顺序和结果可验证 | 多帧底图 + 编号、箭头和短文案 |
| 对比/前后图 | 比较对象、条件和结论可证明 | 对称底图 + 矢量表格或标注 |
| 数据/防护/认证图 | 数据来源、测试条件和授权有效 | 真实底图 + 信息图；不得虚构徽章 |
| 兼容性/接口图 | 型号、尺寸或接口关系已确认 | 局部图 + 矢量型号与连接示意 |
| 情绪/品牌/礼赠图 | 不制造产品功能主张 | 氛围图 + 克制品牌文案 |

## 差异化版式原型（按图片类型）

每种类型配 2–3 个差异化版式原型，让不同类型**天生看起来不一样**；配合「类型配额」驱动，实现套图版式多样化。同一类型在配额内重复出现时，用不同原型/景别/占比/动线拉开差异。若类型已多样但排版千篇一律，判为普通并返回版式规划。

| 图片类型 | 差异化版式原型 | 构图 / 排版要点 | 避免 |
|---|---|---|---|
| 白底首图 | 居中产品 + 干净留白 | 合规固定版式；差异靠产品角度与主体占比 | 加文案 / 装饰 / 衬托物 |
| 多角度展示图 | 三视图排布 / 主体+局部inset / 环绕动线 | 网格或对角排布；主体占主画面、局部作辅助 | 一张图堆太多角度挤爆版式 |
| 场景图 | 全景沉浸 / 非对称主视觉 / 生活化近景 | 前中后景有深度；非对称留白给文案；景别切换 | 产品居中 + 背景平铺无层次 |
| 人物 / 手部图 | 手持特写 / 人物使用中景 / 肢体交互近景 | 视角（俯/平/仰）与人物比例变化；互动焦点清晰 | 所有人物图同视角同比例 |
| 细节 / 微距图 | 微距质感 / 结构局部 / 材质对比 | 浅景深、大比例特写、局部张力 | 细节图与整体图同景别、无放大感 |
| 尺寸 / 比例图 | 矢量尺寸线 / 参照物对比 / 比例分解 | 干净底图 + 矢量标注；参照物比例有证据 | 让图模型伪造尺寸数字 |
| 对比 / 前后图 | 左右分栏 / 上下阶梯 / 对照矩阵 | 对称主体 + 明确分隔；结论可证明 | 无证据的对比结论 |
| 数据 / 防护 / 认证图 | 信息图 / 性能可视化 / 认证标识 | 干净底图 + 矢量图表；信息层级清晰 | 虚构徽章、数字 |
| 步骤 / 功能图 | 分镜序列 / 时间线 / 一图多步 | 多帧 + 编号箭头 + 顺序动线 | 一图塞满多步看不清 |
| 情绪 / 品牌 / 礼赠图 | 情绪氛围 / 品牌故事 / 礼赠场景 | 氛围优先、克制文案、大片留白 | 制造无证据的功能主张 |

## 证据门禁与可用性

### 仅凭实拍 / 结构可见即可（无证据门槛，默认可选）

白底首图、多角度、组合展示、细节/微距、材质/工艺、单一场景、多场景组合、人物/手部、情绪氛围、品牌故事、设计灵感、核心卖点、服务保障、季节、礼赠、目标人群、收纳/便携、痛点解决。

这些类型不需要额外的产品事实，靠实拍与结构可见即可做出，是默认可选的地基。

### 需产品事实 / 证据（缺则标「不可选」并注明缺失事实）

尺寸、比例参照、包装清单、变体展示、结构拆解、剖面/原理、兼容性、接口/适配、成分/配方、数据/性能、防护能力、认证/授权、功能/步骤/安装、清洁/维护、使用前后对比、性能/型号对比、保修与服务承诺。

- 无证据时必须**标记为不可选，并注明缺少的 `unknown` 事实**，而不是模糊地「跳过/降级」。
- 仅在用户提供对应事实、认证或测试数据后，才转为可选。
- 无法补证据时，可降级为弱表达（比例参照/图解/场景暗示），但不得用强主张（具体数值、认证徽章、对比结论）。
